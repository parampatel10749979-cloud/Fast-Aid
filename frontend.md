# Fast-Aid — Frontend Specification & Implementation Blueprint

> **Instruction to AI Studio & Antigravity:**  
> Read this entire document before generating frontend code. Build the Fast-Aid frontend as a **real, interactive, Google Maps-style emergency navigation command center**.
> - **Real Interactive Map:** Look, feel, and function like Google Maps (smooth vector/raster street tiles, pan/zoom/tilt, street labels, realistic roads, route polyline overlays, live vehicle marker, traffic heat lines, and signal preemption beacons).
> - **Clean Frontend Folder:** `frontend/` is reserved exclusively for the web application (HTML5/CSS3/JavaScript or React/TypeScript generated by AI Studio).
> - **Zero Backend Mutation:** Interface with `backend/` via clean API / data contracts without breaking backend mathematical models or algorithms.
> - **Offline & Free Map Option:** Support offline/free map tiles (Leaflet.js + CartoDB / OpenStreetMap Google Maps style) as well as optional Google Maps JavaScript API with dark navigation themes.

---

## 1. Executive Summary & Problem Statement

**Fast-Aid** simulates a smart emergency response network where an ambulance transits a congested city network to reach the optimal hospital.

The frontend serves as an **Interactive Google Maps Emergency Navigation Center**. It visually demonstrates the life-saving benefits of **Fast-Aid (Smart)** mode versus standard routing:

| Routing Mode | Route Cost Function | Dynamic Rerouting | Traffic Signal Preemption (Green Corridor) |
|---|---|---|---|
| **Baseline** | Static Shortest Distance (m) | ✗ Disabled | ✗ Disabled (Stops at Red Lights) |
| **Traffic-Aware** | Live Congestion Travel Time | ✓ Every 15s | ✗ Disabled (Stops at Red Lights) |
| **Fast-Aid (Smart)** | Live Travel Time + Signal Penalty | ✓ Every 15s | ✓ Next 3 Upcoming Signals Forcibly Green |

  - Floating compass & "Recenter on Ambulance" target button.

### 2.2 Realistic Geographic Projection
The simulation operates on a 12×12 grid city ($200\text{ m}$ block spacing). The frontend projects this onto a realistic urban center (e.g. downtown grid coordinates):
```javascript
// Base reference origin (e.g. Downtown Metro Grid)
const BASE_LAT = 37.7749;   // Reference origin latitude
const BASE_LNG = -122.4194; // Reference origin longitude
const LAT_STEP = 0.0018;    // ~200 metres per row
const LNG_STEP = 0.0023;    // ~200 metres per column

function nodeToLatLng(row, col) {
  return [BASE_LAT + (row * LAT_STEP), BASE_LNG + (col * LNG_STEP)];
}
```

### 2.3 Visual Map Elements
1. **Live Traffic Polylines (Google Maps Congestion Coloring):**
   - Green (`#00e676`): Congestion $< 0.35$ (Free flow, $> 45\text{ km/h}$).
   - Amber / Orange (`#ff9100`): Congestion $0.35 - 0.70$ (Moderate slowdown).
   - Crimson / Red (`#ff1744`): Congestion $> 0.70$ (Heavy traffic delay).
   - Dark Burgundy / Black (`#7f0000`): Incident / Road Blockade ($0.95$ congestion).
2. **Three Overlaid Competing Routes:**
   - **Fast-Aid Smart (Primary):** Solid, glowing Emerald Green line (`#00d4aa`, width: 6px) with animated pulsing dash forward arrows.
   - **Traffic-Aware:** Translucent Amber line (`#f59e0b`, width: 4px).
   - **Baseline Shortest Distance:** Translucent Cobalt Blue line (`#3b82f6`, width: 4px).
3. **Signal Preemption Corridor (Green Wave):**
   - Intersections with traffic signals display realistic mini traffic light icons (Red 🔴 or Green 🟢).
   - As the ambulance moves, the **next 3 signals** along its path light up with an animated cyan/emerald halo, representing the **V2X Green Corridor Preemption**.
4. **Animated Ambulance Marker:**
   - Custom SVG ambulance icon with flashing red/blue emergency siren light.
   - Smooth movement along the route with realistic heading/rotation angle towards the next waypoint.
   - Dynamic speed tag: `54 km/h (Siren Active)`.
5. **Hospital Pins & Google Maps InfoWindows:**
   - Distinct Red Cross / White Badge markers on hospital nodes.
   - Clicking a hospital opens a Google Maps-style card:
     - Hospital Name (e.g., *St. Jude Emergency Center*).
     - Capacity: Available Beds (`7 / 12 Beds Free`).
     - Emergency Specialties (`Cardiac`, `Trauma`, `Stroke`).
     - ETA from current ambulance position.

## 4. Backend API Contract (Connecting Frontend to Python Engine)

The frontend communicates with Fast-Aid's Python backend using standard JSON REST endpoints.

### 4.1 Endpoint Reference

#### `POST /api/city` — Generate City Grid
- **Request Body:**
  ```json
  { "seed": 42, "rows": 12, "cols": 12, "scenario": "Heavy" }
  ```
- **Response JSON:**
  ```json
  {
    "nodes": [[0,0], [0,1], ...],
    "edges": [
      { "u": [0,0], "v": [0,1], "length": 200, "congestion": 0.65, "speed_limit": 40 }

      { "node": [11,11], "name": "City Trauma Center", "capacity": 8, "specialties": ["trauma", "cardiac"] }
  ```

## 5. UI Components Breakdown

### 5.1 Google Maps-Style Navigation Card (Top Left)
- Floating glassmorphic card overlaid directly on top of the map.
- Displays origin, destination hospital, and three clickable route options:
  1. **Fast-Aid Smart (Recommended, 🟢):** Shows ETA, time saved %, and "Green Corridor Active" badge.
  2. **Traffic-Aware (Alternative, 🟠):** Shows ETA and delay relative to Smart.
  3. **Baseline (Standard, 🔵):** Shows ETA and delay from signal stops.
- Clicking any route card focuses and highlights that specific polyline on the map.

### 5.2 Simulation Control Dock (Bottom Center)
- **Play / Pause / Replay Buttons:** Starts or pauses ambulance playback.
- **Speed Multiplier:** $1\times, 2\times, 5\times, 10\times$ simulation speed.
- **Progress Scrubber:** Allows dragging forward/backward in simulation time.
- **Live Event Ticker:** Monospace status pill showing real-time operations (e.g. *"🚦 Signal at 5th Ave preempted to GREEN"*).

### 5.3 Dispatch & Triage Drawer (Collapsible)
- Select Traffic Scenario (`Light`, `Moderate`, `Heavy`, `Gridlock`).
- Select Emergency Condition (`Cardiac`, `Trauma`, `Stroke`).
- Algorithm Selection (`Dijkstra` vs `A*`).
- Toggles: `Green Corridor Preemption`, `Dynamic Rerouting`, `Accident Spikes`.
- Big Red Action Button: **"🚨 DISPATCH AMBULANCE"**.

### 5.4 Mode Comparison & Analytics Modal / Tab
- Side-by-side mode telemetry table.
- Trip duration breakdown: Driving Time vs Signal Wait Delay.
- Distribution charts and exportable benchmark records.

## 6. Implementation Steps for AI Studio

1. **Setup Map Canvas:**
   - Instantiate Leaflet or Google Maps in `#map` container.
   - Load street tiles with crisp high-DPI styling.
2. **Render City Network:**
   - Draw edge polylines with traffic congestion gradient colors.
   - Place hospital markers with SVG cross badges and signal nodes with traffic light icons.
3. **Overlay Routes:**
   - Draw Baseline (Blue), Traffic-Aware (Amber), and Smart (Neon Green with glow effect).
4. **Build Animation Engine:**
   - Smoothly interpolate ambulance marker position between path coordinates.
   - Dynamically turn the next 3 traffic signal markers to GREEN with a glowing circular ripple effect.
   - Play siren animation badge when in motion.
5. **Connect Telemetry & Controls:**
   - Update navigation summary card with real ETA and % time saved.
   - Bind dispatch and slider controls to update map in real time.
